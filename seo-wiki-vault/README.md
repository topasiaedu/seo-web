# SEO Wiki Vault

LLM-maintained knowledge vault for the `seo-website` monorepo.

Follows the **LLM wiki** pattern ([Karpathy](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)):

1. **`raw/`** — immutable sources (research dumps, clipped articles)
2. **`wiki/`** — compiled, interlinked knowledge (agent-maintained)
3. **`AGENTS.md`** — schema and workflows agents must follow

## For humans

- Browse `wiki/` (Obsidian-friendly markdown).
- Drop new sources into `raw/inbox/`, then ask an agent to **ingest**.
- Use `scratch/` for personal notes the agent should not own.

## For agents

Read [AGENTS.md](AGENTS.md) first, then [wiki/index.md](wiki/index.md) and [wiki/overview.md](wiki/overview.md).
